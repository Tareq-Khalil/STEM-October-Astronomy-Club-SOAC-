How It Works

  • Instructors create rooms and receive a 6-digit code
  • Teams join using the room code and their team code
  • Each question has a 30-second thinking period
  • First team to buzz in gets to answer
  • +1 point for correct answers, no penalties
  • If wrong, opponent gets 5 seconds to answer
  • After 20 questions, instructor declares the winner
  • Winners advance to the next round automatically
